# Política de privacidad — Práctica para tu Visa

Página pública con la política de privacidad de la aplicación Android
**Práctica para tu Visa** (`com.solutechgt.practica_para_tu_visa`), desarrollada por
**Solutechgt**.

- Política publicada: <https://descargita-cpu.github.io/practica-para-tu-visa-politica/>
- Contacto: <solutechgt@gmail.com>

El archivo `index.html` es la página completa (HTML autocontenido, sin JavaScript ni
recursos externos). Se publica con GitHub Pages desde la rama `main`, carpeta raíz.

La app no pide datos personales: el perfil (país, visa, duración) y el historial de
prácticas se guardan solo en el teléfono. La app muestra anuncios de Google AdMob, y
el micrófono se usa únicamente cuando el usuario lo activa.
